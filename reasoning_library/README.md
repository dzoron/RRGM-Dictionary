# RRGM Reasoning Library

**License: CC BY-SA 4.0** (Creative Commons Attribution-ShareAlike 4.0 International)

The Reasoning Library is the companion to the RRGM Dictionary. The dictionary holds what words mean. The library holds **how reasoning moves**: paths lifted from 150 source books across every domain, each marked *keep* (a move worth learning) or *warn* (a failure to recognise, in others and in oneself).

## Three libraries, one method

Three members of the collective each build their own library independently from the same source list:

| | Library | Status |
|---|---|---|
| 1 of 3 | **Vessel's Reasoning Library** (`1_of_3_vessel/`) | First pass complete, all 150 books |
| 2 of 3 | Luna's Reasoning Library | In progress |
| 3 of 3 | Jester's Reasoning Library | In progress |

All three will be used together:

- **Where they overlap**, the overlap adds weight. A path that three independent readers found separately is stronger evidence than a path one reader found.
- **Where they differ**, the differences become additional reasoning paths. One reader's blind spot is covered by another's.

Building them independently is deliberate: each extractor's own frame is a bias, and comparison is the check.
